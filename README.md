# Конкурсные списки магистратуры ИТМО

Telegram-бот: сохраняет уникальный код поступающего, ходит в официальные списки ИТМО и показывает место в общем конкурсе и среди тех, у кого выбранная программа — первый приоритет.

Программы задаются в `config.yaml` — можно добавлять сколько угодно.

## Запуск

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
```

Токен бота возьмите у [@BotFather](https://t.me/BotFather) и пропишите в `.env`:

```
BOT_TOKEN=123456:ABC...
```

Если бот крутится в РФ (Yandex Cloud, Selectel и т.д.), `api.telegram.org:443` обычно недоступен, даже когда `ping` проходит. Тогда в `.env` нужен прокси за границей:

```
TELEGRAM_PROXY=socks5://127.0.0.1:1080
```

или `http://user:pass@host:8080`.

Запуск:

```bash
python -m src
```

Проверка парсера без Telegram (код `2053628`, программа `2379`):

```bash
python -m src --dump 2053628 2379
```

## Как добавить программу

В `config.yaml`:

```yaml
programs:
  - name: "Веб-технологии"
    short: "Веб"
    url: "https://abit.itmo.ru/rating/master/budget/2379"
```

`url` — страница списка на [abit.itmo.ru](https://abit.itmo.ru). Из него берутся ступень (`master`), финансирование (`budget`) и id конкурсной группы.

## Что показывает сводка

Поля как на сайте: место, приоритет, вид испытания, ВИ / ИД / ВИ+ИД, средний балл диплома, согласие, основной высший и высший проходной приоритет, пометка «рекомендован».

Дополнительно: сколько человек впереди (с баллами, с 1 приоритетом, с согласием) и отдельное место среди заявлений с приоритетом 1.
